# Entities

* [ninja_ble Package](ninja-ble.md) - Bluetooth Low Energy peripheral service package implementing GATT characteristics and binary chunking.
* [ninja_core Package](ninja-core.md) - Core application package containing HAL, dispatcher, web server, safe executor, and AI agent.
* [ninja_utils Package](ninja-utils.md) - Shared utilities package containing Abstract Base Classes, centralized logging, and systemd service managers.
* [ninja_webapp Package](ninja-webapp.md) - Mobile-first React 18 SPA frontend providing real-time controls, AI chat, telemetry, and internationalization.
* [NinjaRobot V5 Entity](ninjarobot-v5.md) - Complete hardware platform entity specifications, configurations, robot types, and safety lifecycle.
* [pi0buzzer Package](pi0buzzer.md) - Non-blocking passive buzzer driver with musical notes, 14 emotion sound signatures, and keyboard piano.
* [pi0disp Package](pi0disp.md) - Thread-safe SPI display driver for ST7789V LCDs with smart delta rendering and multilingual text tickers.
* [pi0servo Package](pi0servo.md) - Velocity-based servo control library for SG90/MG90S servos with cubic easing and interactive calibration.
* [pi0vl53l0x Package](pi0vl53l0x.md) - Hardened VL53L0X Time-of-Flight distance sensor driver with transaction-level locking and bus recovery.
